## Что было найдено и исправлено при проверке

Перечислено, потому что каждая из этих ошибок воспроизвелась бы у следующего исполнителя.

| Проблема | Причина | Исправление |
|---|---|---|
| Миграции получали отказ в соединении при первом запуске | Healthcheck PostgreSQL срабатывал на временном сервере инициализации, который слушает только unix-сокет и затем перезапускается | Проверка готовности по TCP: `pg_isready -h 127.0.0.1` (Compose, CI, скрипт интеграционных тестов) |
| Keycloak не стартовал | `sozhiteli://` — недопустимый URI возврата после выхода | `sozhiteli://auth/signed-out` |
| edge не стартовал | В nginx нет формы `limit_req off` | Ограничение частоты задано в маршрутах API, а не на уровне сервера |
| Контрактный тест не находил операцию | oapi-codegen меняет регистр `operationId` во встроенной спецификации | Сопоставление без учёта регистра в `openapitest` |
| `go tool -modfile` не работал | Несовместим с режимом `go.work` | `GOWORK=off` для кодогенерации |
| openapi-typescript требовал настроек вывода | Подхватывал `redocly.yaml` из корня | Конфигурация Redocly перенесена в `contracts/` |
| Линтер mobile падал | `eslint-plugin-react` использует API, удалённый в ESLint 10 | Версия React задана в настройках линтера явно |
| `expo-doctor` ложно сообщал о трёх ошибках | Флаг `npm run -s` передаёт тихий режим вложенным вызовам npm | Не использовать `-s` с этой командой; отмечено в `README.md` |
| Пул Keycloak мог занять все соединения PostgreSQL | Значение по умолчанию — до 100 соединений | `KC_DB_POOL_MAX_SIZE=20` |
