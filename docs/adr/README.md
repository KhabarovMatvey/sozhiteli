## Как добавить ADR

1. Новый файл `NNNN-краткое-имя.md` со следующим номером и той же структурой разделов.
2. Статус: `предложено` → после согласования с владельцем архитектуры `принято`.
3. Принятый ADR не переписывается. Если решение меняется, создаётся новый ADR, а в старом
   статус меняется на `заменено ADR-NNNN`.
4. Строка в таблице выше.

ADR обязателен для: нового сервиса, новой инфраструктурной технологии, нового межсервисного
взаимодействия, изменения границ сервисов или владения данными, изменения способа аутентификации.
